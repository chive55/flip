# Flip

Tap to flip gravity (floor ↔ ceiling). Dodge neon spikes while the world speeds up.

## Controls
- Tap / click / Space — flip gravity
- Mute button — toggle sound

## Dev
```bash
npm install
npm run dev
npm run build
```
